## v11 Installation Changes

Starting with this major, RevenueCat's Apple dependencies are no longer published to CocoaPods. Swift Package Manager (SPM) is the supported way to integrate RevenueCat on Apple platforms.

Before upgrading, follow the [Unity CocoaPods-to-SPM migration guide](https://rev.cat/unity-spm-migration). Migrate both the core and UI packages if your app uses RevenueCat UI.
